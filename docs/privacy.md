# Privacy

What Maple Classic Exp Overlay keeps on your PC, and the only things it ever sends.

- **Your log, your notes and your settings stay on your PC**, in `%APPDATA%\MapleEXP` (`~/Library/Application Support/MapleEXP` on a Mac). Notes are part of your log file: they are never sent anywhere, and the overlay's tests check that.
- **A copy of your log is kept for each day** (the last 7 days), in the `backups` folder next to it, so if anything ever goes wrong there's a recent one. To go back to one, close the overlay and copy it over `exp_log.json`.
- **Potions stay here too.** Your potion counts, prices and costs are never sent anywhere.
- **The update check** (on by default, can be turned off in ⚙) asks GitHub for the newest version and what's new in it. GitHub sees your internet address and the overlay's version, like any website you visit; nothing else about you is sent.
- **Buttons that open your browser** (Best maps, Report on GitHub, the update's download page) only do it when you click them. Best maps puts your level, party size and class in the website's address, so the website sees them.
- **15-minute runs are only shared if you said yes.** Each one is the map, when you farmed it, your level, class and party size, the EXP and mesos you got (EXP only if the mesos couldn't be trusted), the overlay's version, and a random ID made by your copy of the overlay. Never your character's name, your game account or your Windows user name.
- **Daily health reports are only sent if you said yes** (you're asked once; you can change it any time in Settings). Once a day the overlay sends numbers about the day before: the overlay's version, your Windows or macOS version, your screens' sizes and scaling, the game window's size (and the height of the EXP digits on screen), how the overlay captures the screen (whole screen, game window or selected area), whether its text reader (Tesseract) works, how many times it looked at the game and how each look went (for example how often it found the EXP bar), how many times the level, class, map name, mesos and potion readers worked, how long a look takes, how long you tracked, how often the newer readers (for EXP, mesos and party size) agreed with the older ones and how long they take, how many looks were at each game UI size (Default or Ideal) and each potion bar layout (keyboard or controller), how many looks saw the game's "Default Ratio (Filter Applied)" on, off, not known yet, or at a size where it changes nothing, and the names of any errors (just the kind, like `TesseractError`). Never your character's name, chat, maps, class, amounts, pictures, file paths or your log. It carries a random ID made only for these reports (kept in your settings, and not the same as the ID on shared runs, so the two can't be joined). The website keeps them for 90 days, never shows them on the site, and uses them only to find and fix reading problems. The numbers about potions are only how often the overlay could read the potion bar, and which layout it was, not which potions or how many you used. Every number is a count or a number of milliseconds.
- **The website keeps** those runs. To limit spam it also keeps a scrambled code made from your internet address with a secret key, which changes every day and can't be turned back into the address. Your address itself isn't kept.
- **Bug reports** only go to GitHub if you click Submit there yourself, or to the website if you click **Send to the developer** (you see exactly what is sent first). Send to the developer is text only: what you typed, plus the same details text as the GitHub report (your version, screen and game window sizes, what the overlay found, the map name and class it read, how the potion bar was read (the layout, the UI size, each slot's item and the count it read or why it couldn't, the potion cost line as shown, and which shipped items you set your own price for, never the prices you set), its settings, what it last said, and the end of its error list), with file paths cut down to the file name and your Windows or Mac user name and computer name taken out. No pictures, no chat. It carries the random ID used only for reports (the same one as the daily health report, not the one on shared runs), up to 3 a day. After sending, you get the report's number (to give on GitHub or Reddit if you'd like a reply). The website keeps it for 90 days, never shows it on the site, and reads it only to fix problems.
